# Analysis Plan

## Disease
Glioblastoma (GBM)

## Objective
Identify molecular features associated with glioblastoma biology, treatment response, and clinical outcomes using publicly available datasets.

## Data sources
- TCGA-GBM
- GEO
- cBioPortal
- Public single-cell RNA-seq datasets

## Planned analyses
1. Clinical and molecular data exploration
2. Differential gene-expression analysis
3. Survival analysis
4. Pathway enrichment
5. Independent cohort validation
6. Single-cell assessment of candidate genes
7. Selection of biologically relevant targets for possible experimental validation

## Computational tools
- R
- Python
- Git/GitHub
- Statistical modeling
- Machine learning
- Cancer genomics and transcriptomics

## Potential translational extension
Selected findings may be evaluated using:
- GBM cell culture
- Drug perturbation
- Cell viability assays
- qRT-PCR
- Migration assays
